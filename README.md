# MedAnalyzer

Вебзастосунок для цифровізації, централізованого зберігання та аналітики результатів лабораторних досліджень крові. Система забезпечує автоматизоване вилучення даних із фотографій бланків за допомогою технології OCR та візуалізацію динаміки показників здоров'я.

---

###  Технологічний стек

+ **Server-side:** Node.js (v18+), Express.js (REST API, MVC Pattern)
+ **Database:** MongoDB + Mongoose (NoSQL)
+ **Data Processing:** Tesseract.js (OCR / WebAssembly), Custom Parser Service
+ **Client-side:** HTML5, CSS3, JavaScript (Vanilla), Chart.js
+ **Infrastructure:** Docker & Docker Compose, Render Cloud Hosting

---

###  Функціональні можливості

> **Автентифікація та Безпека**
> Реалізовано захищений вхід та реєстрацію користувачів із використанням JWT-токенів та хешування паролів.

> **OCR-сканування**
> Підтримка завантаження файлів (JPG/PNG) або захоплення зображення безпосередньо з камери пристрою в реальному часі.

> **Інтелектуальний Парсинг**
Алгоритм автоматично очищує текст, анонімізує персональні дані та структурує результати, коригуючи типові помилки розпізнавання.

> **Валідація та Аналітика**
Автоматичне порівняння отриманих значень із референтними нормами. Побудова інтерактивних графіків для відстеження динаміки змін показників у часі.

#### 1. Попередні вимоги
Для коректної роботи системи необхідно встановити:
+ Node.js (v18.0.0 або вище)
