# MedAnalyzer

[cite_start]Вебзастосунок для цифровізації, централізованого зберігання та аналітики результатів лабораторних досліджень крові[cite: 16, 84]. [cite_start]Система забезпечує автоматизоване вилучення даних із фотографій бланків за допомогою технології OCR та візуалізацію динаміки показників здоров'я[cite: 17, 85, 86].

---

### Технологічний стек

+ [cite_start]**Server-side:** Node.js (v18+), Express.js (REST API, MVC Pattern) [cite: 18, 349, 350]
+ [cite_start]**Database:** MongoDB + Mongoose (NoSQL) [cite: 19, 242, 294]
+ [cite_start]**Data Processing:** Tesseract.js (OCR / WebAssembly), Custom Parser Service [cite: 183, 402, 406]
+ [cite_start]**Client-side:** HTML5, CSS3, JavaScript (Vanilla), Chart.js [cite: 18, 492, 495]
+ [cite_start]**Infrastructure:** Docker & Docker Compose, Render Cloud Hosting [cite: 19, 251]

---

### Функціональні можливості

> **Автентифікація та Безпека**
> [cite_start]Реалізовано захищений вхід та реєстрацію користувачів із використанням JWT-токенів та хешування паролів[cite: 41, 269, 271].

> **OCR-сканування**
> [cite_start]Підтримка завантаження файлів (JPG/PNG) або захоплення зображення безпосередньо з камери пристрою в реальному часі[cite: 255, 361, 508].

> **Інтелектуальний Парсинг**
> [cite_start]Алгоритм автоматично очищує текст, анонімізує персональні дані та структурує результати, коригуючи типові помилки розпізнавання[cite: 410, 449, 463].

> **Валідація та Аналітика**
> Автоматичне порівняння отриманих значень із референтними нормами. [cite_start]Побудова інтерактивних графіків для відстеження динаміки змін показників у часі[cite: 258, 493, 523].

#### 1. Попередні вимоги
[cite_start]Для коректної роботи системи необхідно встановити[cite: 560, 561, 562]:
